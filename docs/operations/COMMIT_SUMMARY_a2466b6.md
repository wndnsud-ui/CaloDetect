## 핵심 수정 사항

### 1. 화면 표시 이름을 닉네임으로 통일
- 회원 이름이 보이는 곳은 모두 **닉네임**으로 표시한다.
  - 상단 헤더 (`○○님의 계정`, `○○님의 식단 기록`)
  - 사이드바 하단, 내 정보 프로필(이름·첫 글자)
  - 소개 페이지 환영 문구
  - 커뮤니티 피드 작성자, 커뮤니티 포인트 랭킹
- 닉네임이 아직 없는 회원만 계정 이름을 대신 쓴다.
- 계정 이름은 내 정보의 "이름" 입력란에만 남는다. 안내 문구는 "계정 이름이에요 · 화면에는 닉네임이 표시돼요"로 바꿨다.
- `PENDING_DECISIONS`에 미결로 있던 "이름·닉네임 통합 여부"는 이번 결정으로 해소했다.

```text

└── 리워드몰                         (기존 '리워드', 보유 포인트 표시 유지)

[유틸리티 영역]
├── 내 정보 & 설정                   (비로그인 시 '로그인 / 회원가입')

│     │     └── [하위 탭] 건강 목표 (기존 '목표 설정' 메뉴)
│     ├── [탭] 지방이 성장
│     │     ├── [하위 탭] 내 방 꾸미기 (기존 '지방이 방')
│     │     └── [하위 탭] 성장 · 랭킹
│     └── [탭] 쿠폰함               (교환 기능 켜짐 시에만)

└── 테스트                           (로컬 개발 테스트 계정만)
```

#### 화면 동작
- 메인 메뉴는 안쪽 탭 화면에 있어도 선택 상태를 유지한다. 예를 들어 '영양 분석 리포트'를 보는 중에도 '식단 관리'가 선택돼 있다.
- 각 묶음 화면 맨 위에 메뉴 제목(`식단 기록`, `식단 관리`, `내 정보 & 설정`)과 탭 버튼을 표시한다.
- 마이페이지 안에 있던 기존 탭 줄(회원정보 · 지방이 방 · 성장·랭킹 · 쿠폰함)은 위의 탭 구조로 바꿨다.
- **데스크톱:** 사이드바에 메인 6개를 두고, 그 아래 유틸리티 영역에 내 정보 & 설정 · 관리자 · 테스트를 둔다.
- **모바일(760px 이하):** 메인 6개는 화면 하단에 같은 폭으로 배치하고, 내 정보 & 설정은 상단 오른쪽 버튼으로 들어간다.
- 메뉴 아이콘: '오늘 뭐먹지?'는 셰프 모자에서 접시·포크·나이프로, '식단 관리'는 시계에서 막대그래프가 들어간 달력으로 바꿨다.

#### 그대로 둔 것

- 로그인 필요 여부, 관리자·테스트 권한 검사, 채팅 기록·쿠폰함 기능 플래그
- 신규 API·DB 변경 없음
