# 리워드몰 이미지 자산

## 현재 상품 사진

2026-10-27 사용자 승인으로 상품 14종을 AI 고해상도 사진으로 재제작한다. 각 상품 폴더의 `hero-hd.png`가 현재 대표 사진이며 상품 목록·상세·교환 확인·홈 광고·기획전 추천/라인업에서 공통으로 사용한다. 이전 ZIP 확대 이미지는 보존하지만 상품 갤러리에는 노출하지 않는다.

- 간편식·음료 7종: 기존 상품의 재료·색감과 분위기를 참고해 새 사진을 제작. 새 대표 사진과 이전 고해상도 `hero-no-video.png` 사진을 갤러리에 제공.
- 홍삼 7종: 기존 포장색(녹색·베이지·검정·샴페인 골드)과 상자/스틱 형태를 참고해 새 대표 사진을 제작. 작은 기존 썸네일은 제외.
- 사진 내부의 작은 글자·의료 효능·가짜 재생 버튼·로고는 생성하지 않는다. 상품명과 설명은 실제 서버 문자열을 HTML로 렌더링한다.
- 과거의 저해상도 상세 광고 이미지는 상품 사진과 HTML 소개 영역으로 대체한다.
- 생성물은 실제 촬영된 제휴 상품 사진이 아닌 시연용 이미지다. 실제 브랜드 상품을 판매할 경우 해당 실물과 일치하는 사진으로 교체해야 한다.

생성 방식: `image_gen` 내장 도구. 참고 파일은 각 상품의 기존 `hero.jpg` 또는 `hero-no-video.png`. 요청: 단일 4:3 스튜디오 제품 사진, 제품 전체 프레임 안에 배치, 실제 질감 재구성, 문구·워터마크·콜라주 제외. 실제 파일 해상도와 배포 복사는 작업 후 검사한다.

검증: 생성된 14개 PNG 모두 1448×1086px. 빌드 결과 파일의 SHA256이 원본과 모두 일치. Node 테스트 6개 통과, Vite 빌드 통과. 테스트 데이터로 공통 상품 상세를 Chrome headless 1440px·390px에서 열어 이미지 로딩, 두 사진 간 전환, 가로 넘침 없음을 확인했다. 실제 계정·교환 API 검증은 이번 이미지 작업에 포함하지 않았다.

## 저장 및 배포

리워드몰 이미지는 ZIP이 아닌 개별 파일로 저장하고 배포한다.

| 저장소 경로 | 용도 | 배포 경로 |
|---|---|---|
| frontend/public/rewards/products/ | 상품 대표·썸네일·상세 광고 | /rewards/products/ |
| frontend/public/rewards/collab/ | 기획전 배너·추천·라인업 | /rewards/collab/ |
| frontend/public/rewards/coaches/ | 코칭 사진·배너 | /rewards/coaches/ |

Vite는 `public`의 파일을 빌드 출력 `dist`로 그대로 복사한다. `src`에 중복 저장하거나 서버에서 ZIP을 해제할 필요가 없다. 이 파일들은 Git에 포함해야 한다. 원본 ZIP은 제작 자료이며 서비스 실행·배포에 필요하지 않다.

2026-10-27: 사용자 제공 `CaloPoint_images_4x.zip`에서 기존 이미지에 대응하는 72개 파일을 교체했다. 일반 상품 썸네일은 약 360×300px, 상세 광고는 약 3764×3696px이다. 확대본이므로 실제 촬영 원본의 디테일 증가를 의미하지 않는다.

에너지바·프로틴바·닭가슴살 샌드위치·에너지 드링크·그릭요거트·피타 샌드위치·샐러드 박스 대표 이미지는 `hero-no-video.png`를 사용한다. 확대 ZIP의 대표 이미지에는 '동영상 보기'가 남아 있어 기존 편집본을 유지했다. 연결은 `frontend/src/rewardMallUtils.js`의 `imageUrl`이 담당한다.

원본 비율을 유지하는 현재 배너·갤러리 배치를 유지한다. 이미지 키·상품 ID·가격·교환 정책은 변경하지 않는다.
