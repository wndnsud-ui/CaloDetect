## 1. 개요

### 1.1 목적
CaloDetect의 포인트·성장·리워드 기능을 하나의 사용자 경험으로 통합한다. 음식 인식과 식단 기록이 실제 보상과 장기적인 건강 행동으로 이어지게 하는 것이 목적이다.

### 1.2 핵심 순환 구조

> **Detection → 식단 기록 → 건강 행동 → 포인트·XP 적립 → 작은 보상 → 장기 보상 → 건강 행동 지속**

핵심 경험:

> **내가 건강 행동을 한 만큼 실제 가치가 쌓인다.**

### 1.3 타깃 사용자
- 만 18세 이상 회원 (서비스 가입 기준과 동일)
- 식단 기록을 시작했지만 꾸준히 이어가기 어려워하는 사용자
- 단순 칼로리 계산보다 **동기와 보상**이 필요한 사용자

### 1.4 현재 서비스 상태 (기획 출발점)
- 운영 중인 기능은 커뮤니티 포인트(좋아요·추천 반응 적립, 취소·삭제 시 감점), 포인트 잔액, 주간 랭킹이다.
- **식단 기록과 포인트는 아직 연결되어 있지 않다.** 이 기획의 핵심 변경은 이 연결이다.
- 포인트 사용처(칼로몰·코칭)는 방향만 정해졌고, 교환 비율·소멸·환불 정책은 미정이다.
- 기존 서비스 로드맵에서 포인트 사용처·챌린지·코칭은 후속 범위로 분류되어 있다. 따라서 **이 기획안의 승인은 곧 범위 변경 승인**을 의미한다.

### 1.5 성공 지표 (KPI)

| 구분 | 지표 | 의미 |
|---|---|---|
| 핵심 | D7 / D30 기록 리텐션 | 가입 후 7일·30일째에 식단을 기록한 사용자 비율 |
| 핵심 | 활성 사용자 일 평균 기록 끼니 수 | 기록 습관의 깊이 |
| 온보딩 | 첫날 꾸미기 전환율 | 가입 당일 첫 아이템을 구매한 비율 (목표 경험 2.1 달성 여부) |
| 성장 | 7일 연속 기록 달성률 | 첫 주 습관 형성 |
| 리워드 | 목표 리워드 설정률 | 다음 보상을 의식하는 사용자 비율 |
| 리워드 | 첫 실물 교환 도달 기간 (중앙값) | 중기 목표의 적정 난이도 |
| 경제 | 사용자당 월 실물 교환 비용 | 비용 지속 가능성 (6장) |
| 경제 | 디지털 소비 비중 | 전체 사용 포인트 중 꾸미기·보호권 비율 |
| 건강 | 영양 균형 미션 달성률 | 보상이 건강 행동과 연결되는지 확인 |

> 수치 조정(적립량·가격)은 이 지표를 근거로 한다. 출시 후 4주 단위로 점검한다.

## 2. 재화 체계

CaloDetect는 성격이 다른 **두 가지 재화**를 운영한다.

| 구분 | CaloPoint (P) | Growth XP |
|---|---|---|
| 성격 | 사용할 수 있는 서비스 재화 | 성장 경험치 |
| 사용 | 꾸미기, 건강상품, AI 서비스, 코칭 | 사용 불가. 레벨로만 표시 |
| 감소 | 사용, 소멸, 부정 적립 회수 시 감소 | 부정 적립 회수 외에는 감소하지 않음 |
| 주 획득 경로 | **건강 행동** (식단 기록, 연속 기록, 미션) | 건강 행동 + **커뮤니티 활동** |
| 역할 | 실제 가치 | 지속성의 시각화, 랭킹 기준 |

### 2.1 설계 원칙
1. **실제 가치(CaloPoint)는 건강 행동에서만 나온다.** 다른 사용자의 반응처럼 서로 주고받을 수 있는 행동은 XP로 보상한다. 이렇게 하면 계정끼리 반응을 주고받아 실물 가치를 만드는 담합을 원천적으로 줄일 수 있다.
2. **포인트를 써도 성장은 줄지 않는다.** 사용자는 소비를 망설이지 않아야 한다.
3. **랭킹은 XP 기준으로 운영한다.** 포인트 기준이면 교환할수록 순위가 떨어져 사용을 억제하게 된다.

### 2.2 포인트 사용 구간

| 구간 | 포인트 범위 | 사용처 | 도달 시점 (예상) |
|---|---:|---|---|
| SMALL | 10~150P | 캐릭터·프로필·테마 꾸미기 | 첫날~첫 주 |
| MEDIUM | 200~600P | 실제 건강상품 | 2주~6주 |
| LARGE-AI | 700~1,000P | AI 분석·플랜 | 2개월 전후 |
| LARGE-전문가 | 1,500P 이상 | 전문가 상담·코칭 | 3개월 이상 |

> 구간이 겹치지 않도록 v3의 AI 서비스 가격을 조정했다(500P → 700P부터). 500~600P 구간은 건강상품 전용이다.

## 3. 적립 정책

포인트는 단순 클릭보다 **확정된 건강 행동**에 더 높은 가치를 둔다.

### 3.1 공통 규칙 (v4에서 확정)

| 규칙 | 내용 |
|---|---|
| 끼니당 1회 | 같은 날 같은 끼니(아침·점심·저녁)는 여러 번 기록해도 1회만 지급 |
| 사진 기록 우대 | 사진 분석을 거친 기록은 정상 지급. 사진 없이 음식을 직접 선택한 기록은 절반(+1P) 지급 |
| 기록 인정 기간 | 오늘과 전날 식단까지 포인트 지급. 그 이전 날짜는 기록은 가능하지만 포인트·연속 기록에 반영하지 않음 |
| "기록한 날" 정의 | 하루 1끼 이상 기록하면 연속 기록 일수에 포함 |
| 온보딩과 일일 적립 | 별도 지급. 첫 식단 기록 시 온보딩 +10P와 끼니 +2P를 모두 받음 |
| 기록 경로 | 사진 기록, 채팅 기록 등 경로와 관계없이 같은 기준 적용 |
| 기록 삭제 | 삭제한 기록으로 받은 포인트·XP는 회수 |

### 3.2 신규 사용자 온보딩 (1회)

| 행동 | 포인트 |
|---|---:|
| 회원가입 완료 | +10P |
| 건강 목표 설정 완료 | +10P |
| 첫 식단 기록 완료 | +10P |

**첫날 확보 가능: 온보딩 30P + 당일 기록분 → 약 35~40P**

### 3.3 일일 적립

| 행동 | 포인트 | 한도 |
|---|---:|---|
| 아침 / 점심 / 저녁 기록 | 각 +2P (직접 기록 +1P) | 끼니당 1회 |
| 간식 기록 | +1P | 1일 1회 |
| 하루 3끼 기록 완료 | +3P | 1일 1회 |
| 오늘의 미션 완료 | +2P | 1일 1회 |
| 커뮤니티 식단 공유 | +1P | 1일 1회 |

**하루 최대 13P, 일반적인 활성 사용자 기준 약 8~12P**

> **간식에도 포인트를 주는 이유**: 간식을 빼고 기록하면 영양 데이터가 왜곡된다. 정직한 기록을 장려하는 것이 목적이며, 금액을 낮게 잡아 많이 먹는 것을 보상하지 않도록 했다.

### 3.4 보너스 (반복 여부 확정)

| 조건 | 포인트 | 지급 주기 |
|---|---:|---|
| 연속 기록 3일째 | +5P | 7일 주기로 반복 (3·10·17일째 …) |
| 연속 기록 7일째 | +10P | 7일 주기로 반복 (7·14·21일째 …) |
| 주간 미션 완료 | +15P | 주 1회 |
| 월간 목표 달성 | +30P | 월 1회 |

연속 기록이 끊기면 일수는 0부터 다시 시작한다. 보호권(4.1)을 쓰면 하루를 보호할 수 있다.

### 3.5 커뮤니티 활동 (XP 중심)

| 행동 | 포인트 | XP | 비고 |
|---|---:|---:|---|
| 식단 공유 | +1P | +10 XP | 1일 1회 |
| 좋아요 받기 | — | +5 XP | |
| 추천 받기 | — | +10 XP | |
| 좋아요·추천 누르기 | — | +2 XP | 1일 상한 20 XP |

- 반응 취소, 게시물 삭제 시 관련 XP·포인트 회수 (현재 커뮤니티 감점 정책 유지)
- 본인 게시물에는 반응할 수 없음 (현재 정책 유지)

> **현재 운영값과의 차이**: 지금은 추천 받기 +3P, 반응 누르기 +1P로 포인트를 지급한다. 추천 1회가 식단 1끼 기록(+2P)보다 가치가 커서 "건강 행동 중심" 원칙과 맞지 않는다. 실물 교환이 시작되기 전에 XP 방식으로 전환한다. 이미 적립된 커뮤니티 포인트는 유지한다.

## 4. 사용처

### 4.1 캐릭터 꾸미기 · 디지털 아이템 (SMALL)

| 등급 | 가격 | 예시 |
|---|---:|---|
| 스타터 | 10~30P | 기본 스티커·안경·리본(10P), 기본 모자·운동화(20P), 기본 배경(30P) |
| 중급 | 40~80P | 특별 배경, 계절 아이템, 테마 의상, 운동복 |
| 희귀 | 100~150P | 한정판 코스튬, 이벤트 배경, 시즌 캐릭터 세트 |
| 기능 아이템 | 30P | **연속 기록 보호권**: 하루 기록을 놓쳐도 연속 기록 유지 (월 2회 한도) |

디지털 아이템은 원가가 거의 없다. 따라서 **꾸미기와 보호권 소비 비중이 높을수록 포인트 경제가 건강해진다**(6장). 시즌·한정 아이템을 정기적으로 내놓아 소비처를 계속 새롭게 유지한다.

### 4.2 실제 건강상품 (MEDIUM)

| 상품 | 포인트 |
|---|---:|
| 프로틴바 | 200P |
| 저당 간식 | 250P |
| 무가당 두유 | 300P |
| 단백질 쉐이크 | 400P |
| 샐러드 쿠폰 | 500P |
| 건강 도시락 | 600P |

**운영 방향**
- 1단계: 교환 신청형 MVP (운영자가 수동 처리)
- 2단계: 모바일 쿠폰형 (배송 없는 방식부터 시작)
- 3단계: 제휴 상품·외부 건강상품 연결
- 교환 조건은 7장(운영 정책) 참조

### 4.3 데이터 기반 리워드 추천

사용자의 실제 식단 기록을 바탕으로 다음 리워드를 추천한다. 단순 상품몰과 차별화되는 지점이다.

```text
식단 기록 → 영양 데이터 분석 → 부족 / 과다 판단 → 맞춤 건강 리워드 추천
```

**단계별 적용**

| 단계 | 근거 | 추천 예시 |
|---|---|---|
| 1단계 (즉시 가능) | 이미 정해진 기준: 목표 칼로리, 당류, 나트륨 | "최근 7일 당류가 기준의 120%예요 → 🍪 저당 간식 250P" |
| 2단계 (선행 결정 필요) | 탄수화물·단백질·지방 목표 비율 | "단백질 섭취가 목표의 72%예요 → 🥤 단백질 쉐이크 400P" |

> 2단계는 **탄단지 목표 비율이 확정된 뒤에** 적용한다. 현재 이 비율은 결정 대기 상태다.

**문구 원칙**
- 추천은 "기록한 식단 기준" 참고 정보다. 단정적인 건강 판단처럼 보이지 않게 한다.
- 예: "기록한 식단 기준으로는 단백질이 조금 부족해 보여요."
- 질병·치료와 연결되는 표현은 쓰지 않는다.

### 4.4 AI 서비스 (LARGE-AI)

| 서비스 | 포인트 |
|---|---:|
| 7일 식단 분석 리포트 | 700P |
| AI 맞춤 식단 플랜 | 850P |
| 영양 패턴 분석 | 1,000P |

AI 서비스는 실물보다 원가가 낮다. 따라서 실물 상품보다 먼저 열어 "큰 보상" 경험을 저비용으로 제공하는 방안도 검토한다(9장 로드맵 대안).

### 4.5 전문가 서비스 (LARGE-전문가)

| 서비스 | 포인트 |
|---|---:|
| 1회 온라인 영양 상담 | 1,500P |
| 전문가 식단 피드백 | 2,000P |
| 4주 식단 코칭 프로그램 | 3,000P |

- 전문가 서비스는 **영양 상담 범위**로 한정한다. 진단·처방으로 오해될 서비스는 제공하지 않는다.
- 4주 코칭은 포인트 전액 대신 **포인트 + 할인** 같은 혼합 방식도 검토한다(6장).

## 5. 성장 시스템 (Growth XP · 캐릭터)

### 5.1 XP 지급표

| 행동 | XP |
|---|---:|
| 끼니 기록 (아침·점심·저녁) | +10 XP |
| 간식 기록 | +5 XP |
| 하루 3끼 기록 완료 | +10 XP |
| 오늘의 미션 완료 | +10 XP |
| 영양 균형 달성 (당류·나트륨 기준 이내, 목표 칼로리 ±15% 이내) | +15 XP |
| 연속 기록 3일째 / 7일째 | +20 / +50 XP |
| 커뮤니티 활동 | 3.5 참조 |

> **영양 균형 기준은 "범위 안"이다.** 목표보다 적게 먹는다고 더 받지 않는다(8.1 건강 윤리 원칙).

활성 사용자 기준 하루 약 50~70 XP를 예상한다.

### 5.2 레벨 구간

| 레벨 | 누적 XP | 예상 도달 | 레벨업 보상 |
|---|---:|---|---|
| LV.1 시작 | 0 | 가입 | 기본 캐릭터 |
| LV.2 기록하는 | 300 | 5일 전후 | 레벨 전용 배경 |
| LV.3 움직이는 | 1,000 | 2~3주 | 레벨 전용 의상 + 50P |
| LV.4 균형 잡힌 | 2,500 | 6~7주 | 레벨 전용 코스튬 + 100P |
| LV.5 건강 습관 | 5,000 | 3개월 전후 | 칭호 + 전용 테마 + 200P |

- 레벨 전용 아이템은 판매하지 않는다. 성장을 해야만 얻는 보상이다.
- 레벨은 내려가지 않는다.
- LV.2를 Day 5 전후에 두어 **첫 주 중반(Day 4~6)의 보상 공백**을 채운다(6.3).

### 5.3 캐릭터 성장 원칙
- 성장은 **기록 지속성, 연속 기록, 영양 균형, 목표 달성, 미션**을 반영한다.
- **체중 변화는 성장 조건에 포함하지 않는다.**
- 캐릭터 외형은 "작아지거나 날씬해지는" 방향이 아니라 **활동적이고 건강해지는** 방향(장비, 표정, 배경)으로 변화한다.

### 5.4 캐릭터명 검토
"지방이"는 친근하지만, 성장할수록 '지방'에서 벗어나는 이야기로 읽히면 체형 비하로 받아들여질 수 있다. 출시 전 사용자 테스트로 반응을 확인하고, 대안 이름을 함께 테스트한다.

### 5.5 주간 랭킹
- 기준을 **주간 획득 XP**로 바꾼다(2.1).
- 표시 이름은 실명 대신 **닉네임**을 쓴다. 보상 경쟁이 커지기 전에 도입한다.

## 6. 사용자 경험 흐름

### 6.1 홈 화면 (Daily Home)

포인트는 숫자가 아니라 **오늘 할 수 있는 행동과 다음 목표**로 보여준다.

```text
오늘의 건강 리워드

🔥 5일 연속 기록 중        LV.2 기록하는 ███░░ 62%

현재 137P   오늘 +8P

다음 목표: 🍫 프로틴바 200P
63P 남았어요 · 예상 약 6일

오늘 저녁까지 기록하면 +2P
하루 3끼 완료 시 +3P
```

- 기존 홈 구성(날짜별 식단, 칼로리 링, 당류·나트륨 카드)은 유지한다. 리워드 영역은 **상단 요약 카드 하나**로 추가한다.
- "예상 달성일"은 최근 7일 실제 적립 속도(보너스 포함)로 계산한다.

### 6.2 Reward Mall

```text
CALO REWARD
[꾸미기] [건강상품] [AI 서비스] [전문 코칭]
```

- 상단에 "지금 구매 가능"과 "다음 건강 리워드"를 함께 보여준다.
- 아직 교환할 수 없는 상품도 노출하되, 남은 포인트와 예상 기간을 표시한다.

### 6.3 목표형 리워드
- 사용자가 상품 하나를 목표로 지정한다.
- 홈과 Mall 상단에 진행률, 남은 포인트, 예상 달성일을 표시한다.
- 목표에 도달하면 즉시 교환으로 이어지는 알림을 보낸다.

### 6.4 첫 7일 사용자 경험

| 일차 | 핵심 경험 | 보상 |
|---|---|---|
| Day 1 | 가입 → 목표 설정 → 첫 기록 → **첫 꾸미기** | 온보딩 30P + 기록분 |
| Day 2 | 기록 → 캐릭터 반응 확인 | 끼니 포인트·XP |
| Day 3 | 3일 연속 보너스 → 두 번째 아이템 구매 | +5P |
| Day 4 | **첫 주간 미션 공개** (예: 채소 포함 끼니 3회) | 미션 진행 표시 |
| Day 5 | **LV.2 달성** → 레벨 전용 배경 해금 | 레벨업 연출 |
| Day 6 | 첫 커뮤니티 공유 유도 | +1P, XP |
| Day 7 | 7일 연속 보너스 + 주간 미션 보상 → **첫 실물 목표 리워드 설정** | +10P, +15P |

> v3에서 비어 있던 Day 4~6에 각각 새로운 이벤트를 배치했다. 이탈이 가장 많은 구간이다.

### 6.5 회수·감점 UX
기록 삭제나 반응 취소로 포인트가 회수될 때는, 처리 전에 **회수될 포인트를 미리 보여주고 확인**을 받는다. 현재 커뮤니티 감점 확인 방식을 모든 회수에 똑같이 적용한다.

## 7. 포인트 경제 · 비용 모델

### 7.1 적립 속도 시뮬레이션

가정: 활성 사용자, 일 평균 10P, 연속 기록 유지, 주간 미션 매주 완료

| 시점 | 누적 포인트 (사용 전) | 도달 가능 리워드 |
|---|---:|---|
| Day 1 | 약 40P | 스타터 아이템 |
| Day 7 | 약 130P | 희귀 아이템 |
| Day 14 | 약 230P | 프로틴바 |
| Day 30 | 약 480P | 단백질 쉐이크 |
| 2개월 | 약 930P | AI 식단 플랜 |
| 3개월 | 약 1,400P | 전문가 상담 근접 |
| 6~7개월 | 약 3,000P | 4주 코칭 |

**월 적립량: 활성 사용자 1인당 약 450P** (일일 300P + 보너스 약 150P)

> 보너스가 전체 적립의 약 30%를 차지한다. "하루 8~12P"만 보면 실제 적립 속도를 과소평가하게 되므로, 모든 예상 기간 표시는 보너스를 포함해 계산한다.

### 7.2 포인트 가치와 비용

- 프로틴바(시가 약 2,500원) = 200P → **1P ≈ 12.5원**
- 활성 사용자 1명이 월 450P를 모두 실물로 교환하면 **월 약 5,600원 비용**
- 꾸미기 소비 비중이 40%라면 **월 약 3,400원**

사용자가 늘수록 비용도 함께 늘어나는 구조다. 따라서 **실물 교환을 시작하기 전에 재원을 확정해야 한다.**

### 7.3 재원 후보

| 재원 | 내용 | 적합 시점 |
|---|---|---|
| 제휴 협찬 | 건강식품 브랜드가 상품을 마케팅 비용으로 제공 (샘플링·신제품 홍보) | 실물 교환 초기 |
| 구독 | 프리미엄 구독자 포인트 적립 가속, 전용 아이템 | 사용자 기반 확보 후 |
| B2B | 기업 웰니스 프로그램으로 기업이 리워드 비용 부담 | 중장기 |
| 광고 | 리워드 Mall 내 브랜드 노출 | 중장기 |

### 7.4 비용 조절 장치

| 장치 | 정책 (제안) |
|---|---|
| 포인트 유효기간 | 적립일로부터 12개월. 만료 30일 전 안내 |
| 실물 교환 한도 | 1인 월 1회 |
| 첫 교환 조건 | 가입 14일 이후, 본인인증 완료 |
| 디지털 소비처 강화 | 시즌 아이템, 연속 기록 보호권 |
| 혼합 결제 | 고가 코칭은 포인트 + 할인 쿠폰 방식 검토 |
| 가격 조정 | KPI(월 교환 비용) 기준 분기별 재검토. 가격 변경은 30일 전 공지 |

## 8. 운영 정책

### 8.1 건강 윤리 원칙

게임화된 식단 기록은 섭식 문제가 있는 사용자에게 해로울 수 있다. 다음 원칙을 모든 보상 설계에 적용한다.

1. **적게 먹을수록 보상받는 구조를 만들지 않는다.** 칼로리 관련 보상은 항상 "목표 범위 안"으로 정의한다.
2. **체중 감량을 보상 조건으로 쓰지 않는다.**
3. **정직한 기록을 보상한다.** 간식이나 과식한 끼니를 기록해도 똑같이 보상한다.
4. **연속 기록이 끊겨도 부정적인 메시지를 보내지 않는다.** "다시 시작해요" 같은 회복 중심 문구를 쓴다.
5. 장기간 목표 칼로리를 크게 밑도는 기록이 이어지면, 보상 대신 균형 잡힌 식사에 대한 안내를 우선 보여준다.

### 8.2 공정성 · 악용 방지

| 악용 유형 | 대응 정책 |
|---|---|
| 같은 끼니 반복 기록 | 끼니당 1회 지급 (3.1) |
| 지난 날짜 몰아서 기록 | 오늘·전날까지만 지급, 연속 기록에 미반영 (3.1) |
| 같은 사진 재사용 | 이미 기록에 사용된 사진과 동일하면 미지급 |
| 사진 없는 기록 남발 | 직접 기록은 절반 지급 |
| 짧은 시간에 3끼 몰아 기록 | 3끼 완료 보너스는 끼니 기록 사이 간격이 충분할 때만 지급 (기준값 결정 필요) |
| 반응 주고받기·다계정 담합 | 반응은 XP만 지급 (2.1). 실물 교환 시 본인인증으로 1인 1계정 |
| 가입 보너스용 계정 생성 | 온보딩 포인트는 실물 교환에 바로 쓸 수 없고 꾸미기에만 사용 가능 (첫 교환 조건 7.4) |
| 이상 패턴 | 단기간 급격한 적립 등 이상 패턴은 교환 보류 후 검토. 부정 적립은 회수 |

> 사진 촬영 시각을 기록 검증에 쓰는 방안도 있다. 다만 사진의 부가 정보(위치 등)는 개인정보 보호를 위해 저장하지 않는 것이 원칙이므로, **촬영 시각만 검증용으로 남길지** 결정이 필요하다.

### 8.3 교환 · 취소 · 환불
- 교환 신청 후 쿠폰 발급 전까지는 취소 가능, 포인트 전액 반환
- 발급된 쿠폰은 취소 불가 (쿠폰 자체 유효기간은 제휴사 정책을 따름)
- 디지털 아이템은 구매 후 환불 불가 (구매 전 미리보기 제공)
- 서비스 측 사유로 교환이 실패하면 포인트 전액 반환

### 8.4 회원 탈퇴 · 계정 상태
- 탈퇴 시 잔여 포인트는 소멸한다. 탈퇴 전 잔액과 소멸 예정 포인트를 안내한다.
- 처리 중인 교환이 있으면 완료 후 탈퇴하도록 안내한다.
- 부정 이용으로 제재된 계정은 교환을 제한한다.

### 8.5 공지 · 약관
- 적립 기준, 유효기간, 교환 한도, 회수 사유를 **리워드 이용약관**으로 명시한다.
- 정책 변경은 최소 30일 전에 공지한다.

| **Phase 3 — 디지털 사용처** | 꾸미기, 연속 기록 보호권, Reward Mall(꾸미기 탭), 목표형 리워드 | 포인트 유효기간·환불 정책 확정 |
| **Phase 4 — 실물 리워드** | 건강상품 교환 신청 → 모바일 쿠폰 → 제휴 상품, 데이터 기반 추천 1단계 | **재원 확보, 본인인증, 악용 방지 정책 적용, 동의서·약관 확정** |
| **Phase 5 — AI · 코칭** | AI 리포트·식단 플랜, 전문가 상담, 4주 코칭, 데이터 기반 추천 2단계 | 탄단지 목표 확정, 전문가 서비스 범위 검토 |

**로드맵 대안 (검토)**: AI 서비스는 원가가 낮다. 실물 재원 확보가 늦어지면 Phase 4와 5의 AI 부분 순서를 바꿔, AI 리포트를 첫 "큰 보상"으로 먼저 여는 방안을 검토한다.

## 11. 서비스 정의 · 슬로건

### 11.1 기능별 역할
- **Detection**: 행동을 시작하게 하는 진입 기능
- **식단 기록**: 사용자 데이터를 만드는 핵심 기능
- **CaloPoint**: 건강 행동을 실제 가치로 전환하는 보상 기능
- **Growth XP**: 건강 행동의 지속성을 보여주는 성장 기능
- **Reward**: 다시 돌아올 이유를 만드는 리텐션 기능
- **Coaching**: 장기 사용자를 위한 고가치 서비스

### 11.2 최종 서비스 정의

> **CaloDetect는 음식 AI 분석을 시작으로 사용자의 건강 행동을 기록하고, 그 행동을 캐릭터 성장·실제 건강상품·코칭 서비스로 전환하는 AI 건강관리 플랫폼이다.**

### 11.3 슬로건 후보
- 서비스형: **찍고, 기록하고, 건강해진 만큼 돌려받다.**
- 포인트형: **건강한 행동이 CaloPoint가 됩니다.**
- 리워드형: **작게는 나를 꾸미고, 크게는 나를 건강하게.**
- 발표용: **사용자의 건강 행동을 실제 가치로 전환하는 단계형 리워드 시스템**
