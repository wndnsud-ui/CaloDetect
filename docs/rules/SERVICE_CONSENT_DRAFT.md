# CaloDetect 가입 동의 문구 — 검토용 초안

작성일: 2026-10-02. 사용자 요청에 따라 초안만 작성하고 서비스 등록과 운영 적용은 나중에 진행합니다. 이 문서는 `SERVICE_CONSENT_TEXT`로 자동 적용되지 않습니다. 대괄호 항목은 미확정이며 운영자 검토 후 채워야 합니다.

## 가입 화면에 표시할 문구 초안

### 서비스 이용 안내

CaloDetect는 음식 사진 분석, 섭취량에 따른 영양 계산, 식단 기록, 영양 목표 설정과 식사 추천을 제공합니다. 회원가입과 로그인은 만 18세 이상부터 가능합니다. 가입 시 실제 만 나이를 입력해 주세요.

사진 분석 결과는 추정값입니다. 음식명과 섭취량을 확인하고 수정한 뒤 식단을 저장해 주세요. 영양 정보와 추천은 식단 관리 참고용이며 의료 진단이나 치료를 제공하지 않습니다.

이메일 또는 Google·카카오 계정으로 회원가입할 수 있습니다. 소셜 계정으로 인증해도 CaloDetect 가입을 위한 이름·만 나이·동의 확인이 필요합니다. 이미 가입한 이메일과 소셜 계정은 자동 연결되지 않습니다.

동의 거부 권리와 이용 제한: 개인정보 수집·이용 동의를 거부할 수 있습니다. 가입에 필요한 정보에 동의하지 않으면 신규 회원가입과 회원 전용 기능을 이용할 수 없습니다. 가입 없이 제공되는 음식 조회와 영양·목표 계산은 이용할 수 있습니다. 가입 후 사진 분석이나 목표 정보 저장을 사용하지 않는 경우 해당 기능에 필요한 정보를 입력하지 않아도 됩니다.

## 모델 개선 활용 — 폐기 (2026-10-20)

사용자 결정으로 사진을 이용한 모델 개선(재학습)과 그 선택 동의를 폐기했다. 동의 항목·문구 초안은 더 이상 쓰지 않으며 관련 데이터와 API도 삭제했다.

## 확정 전 검토할 사항

- 운영자 명칭과 문의·권리 행사 접수 방법.
- 항목별 보유기간, 탈퇴·삭제 처리, 이미지 원본과 백업 처리. 서버 세션 만료와 DB 데이터 삭제는 구분해 정합니다.
- 실제 배포 환경의 호스팅·위탁·제공·국외 이전 해당 여부와 필요한 안내. 미정 상태에서 특정 국가·업체·처리 조건을 확정하지 않습니다.
- 가입 안내, 개인정보 동의, 기능별 정보 입력, 선택 동의를 화면에서 어떻게 구분할지 검토합니다. 현재 API는 가입 동의 문구 한 건을 저장하므로 여러 필수 동의를 개별 저장하는 정책으로 결정하면 후속 구현이 필요합니다.
- 삭제 요청·탈퇴 기능은 현재 화면에서 제공하지 않습니다. 실제 처리 방법을 확정하기 전에 자동 삭제나 즉시 탈퇴를 약속하지 않습니다.
- Google·카카오 운영 앱 설정과 등록된 HTTPS 반환 URL은 배포 환경에 맞게 확인합니다.
