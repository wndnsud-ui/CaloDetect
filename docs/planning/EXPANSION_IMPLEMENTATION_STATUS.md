# 확장 업무지시서 구현 대조표

기준일: 2026-10-07. 사용자 요청으로 v11, 첨부 v5.2, 시안 반영 v5.3의 모든 기능을 추적한다. 후속 지시: 홈페이지 메인 이미지 보존, 지방이는 말랑한 3D·애니메이션·회전·포인트 성장 제공. 전체 구현 요청이 확장 개발 범위를 승인하지만 데이터·가격·정책의 임의 확정을 승인한 것은 아니다.

`기존`은 이번 작업에서 새로 구현하지 않은 기능이며 이번 세션에서 전체 동작을 재검증한 의미가 아니다. `실험`은 브라우저 프로토타입이며 서버 영속 기능과 다르다. `미완료` 항목을 메뉴만 만들어 완료로 처리하지 않는다.

## 검증

- Playwright: 중복 기록의 실험 보상 중복 방지·참여 없는 보상 방지, 3D canvas·회전·정면·일시정지, 챌린지 참여·완료, 코치 상세, 모바일 화면. 테스트는 모의 API 자료를 사용하므로 실계정 서버 통합 검증과 구분한다.
- React production build, 홈페이지 메인 배너 이미지 보존 확인; 지방이 소개 섹션만 추가.
- 전체 기능 완료 상태가 아니다. 서버 포인트 원장·실제 소셜·실제 코치 연결·외부 연동·학습·배포는 별도의 필수 후속 작업이다.

## 다음 의존성

Core A의 PostgreSQL schema/migration 작업으로 points ledger·캐릭터·활동·챌린지·관계·게시물·공유 동의를 설계한 뒤 브라우저 실험을 서버 API로 교체한다. 실제 코치 명단이 없으면 코치 유형 시안을 실제 코치로 둔갑시키지 않는다. LLM과 운영 배포는 사용자가 개념을 이해한 뒤 제공자·환경을 결정하며 현재 로컬 개발을 막지 않는다.
