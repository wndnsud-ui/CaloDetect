## 미결에서 제외된 결정

- 사진 모델 개선·재학습은 폐기. 동의·후보·QA·DB 구조 제거. 다시 구현할 대기 과제가 아니다.
- 사용자 웹·관리자는 React, Streamlit은 그래프 서버만 유지.
- 리워드 Stage A/B/C 구현 완료. 기능 활성화·운영 개시는 별도다.
- 닉네임 대기기간 폐지, 지방이 레벨별 몸·애니메이션 사용.
- 화면 표시 이름은 닉네임으로 통일(2026-10-22). 계정 이름은 회원정보에만 남긴다.
- 본인인증·전화번호·배송지는 이번 교환 범위에서 제외. 가입 기간·월 한도·출처 제한·첫 보류 장치 구현.
- 테스트 메뉴·더미 API는 로컬 개발 테스트 계정 본인 전용. 일반 사용자·관리자 메뉴에 노출하지 않음.
- 최소 연령 만 18세. 영양 데이터는 기존 CaloDetect_nutrition_all_matched.csv와 class_id/food_name 연결 유지.
- 무료/유료 구분 없음. AI 서비스 몰 탭 제거. 전문 코칭은 시안만 유지.
