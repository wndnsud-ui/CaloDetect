# CaloDetect 가입 동의 문구 — 검토용 초안

작성일: 2026-10-02. 사용자 요청에 따라 초안만 작성하고 서비스 등록과 운영 적용은 나중에 진행합니다. 이 문서는 `SERVICE_CONSENT_TEXT` 또는 `MODEL_IMPROVEMENT_CONSENT_TEXT`로 자동 적용되지 않습니다. 대괄호 항목은 미확정이며 운영자 검토 후 채워야 합니다.

## 가입 화면에 표시할 문구 초안

### 서비스 이용 안내

CaloDetect는 음식 사진 분석, 섭취량에 따른 영양 계산, 식단 기록, 영양 목표 설정과 식사 추천을 제공합니다. 회원가입과 로그인은 만 18세 이상부터 가능합니다. 가입 시 실제 만 나이를 입력해 주세요.

사진 분석 결과는 추정값입니다. 음식명과 섭취량을 확인하고 수정한 뒤 식단을 저장해 주세요. 영양 정보와 추천은 식단 관리 참고용이며 의료 진단이나 치료를 제공하지 않습니다.

이메일 또는 Google·Apple 계정으로 회원가입할 수 있습니다. 소셜 계정으로 인증해도 CaloDetect 가입을 위한 이름·만 나이·동의 확인이 필요합니다. 이미 가입한 이메일과 소셜 계정은 자동 연결되지 않습니다.

동의 거부 권리와 이용 제한: 개인정보 수집·이용 동의를 거부할 수 있습니다. 가입에 필요한 정보에 동의하지 않으면 신규 회원가입과 회원 전용 기능을 이용할 수 없습니다. 가입 없이 제공되는 음식 조회와 영양·목표 계산은 이용할 수 있습니다. 가입 후 사진 분석이나 목표 정보 저장을 사용하지 않는 경우 해당 기능에 필요한 정보를 입력하지 않아도 됩니다.

## 모델 개선 활용 — 별도 선택 동의 초안

기본 가입 동의와 분리해 표시하며 기본값은 동의하지 않음입니다.

수집·이용 목적: 음식 인식 결과 검토와 모델 개선 후보 데이터 관리.

활용 항목: 별도 동의한 사용자의 음식 사진, 인식한 음식명, 사용자가 수정한 음식명, 해당 수정에 대한 관리자 QA 결과와 관련 식별 정보.

보유·이용 기간: **[대기·승인·거절 샘플별 보유기간과 삭제 방법 — TBD]**

동의한 사용자의 수정 결과도 관리자 QA를 거쳐야 학습 후보로 사용할 수 있습니다. 사진을 업로드하거나 음식명을 수정했다는 이유만으로 모델 학습에 자동 사용하지 않습니다. 이 동의를 거부해도 가입·식단 기록 기능을 사용할 수 있습니다.

## 확정 전 검토할 사항

- 운영자 명칭과 문의·권리 행사 접수 방법.
- 항목별 보유기간, 탈퇴·삭제 처리, 이미지 원본과 백업 처리. 서버 세션 만료와 DB 데이터 삭제는 구분해 정합니다.
- 실제 배포 환경의 호스팅·위탁·제공·국외 이전 해당 여부와 필요한 안내. 미정 상태에서 특정 국가·업체·처리 조건을 확정하지 않습니다.
- 가입 안내, 개인정보 동의, 기능별 정보 입력, 선택 동의를 화면에서 어떻게 구분할지 검토합니다. 현재 API는 가입 동의 문구 한 건과 별도 모델 개선 동의를 저장하므로 여러 필수 동의를 개별 저장하는 정책으로 결정하면 후속 구현이 필요합니다.
- 삭제 요청·탈퇴 기능은 현재 화면에서 제공하지 않습니다. 실제 처리 방법을 확정하기 전에 자동 삭제나 즉시 탈퇴를 약속하지 않습니다.
- Google 웹 Client ID와 Apple Services ID·등록된 HTTPS 반환 URL은 추후 등록합니다.

초안의 수집 목적·항목·보유기간·거부 권리 구분은 [개인정보 보호법 제15조의 동의 안내 항목](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1020398563)을 참고했습니다. 실제 수집 항목과 동작은 현재 Backend 모델·API 기준이며, 이 문서 작성으로 미확정 정책이 승인되지는 않습니다.
