# 채팅으로 식사기록 — 사용할 수 있는 말

근거: 통합구현지시서 v9 5.3장(대화 문구·답장 칩)과 8장(대화 해석). 정리일 2026-10-15.

챗봇은 **규칙 기반**(LLM 미사용)이라 아래 표현과 **전체가 일치**할 때만 알아듣습니다. 띄어쓰기, 문장 끝의 `. ! ~`, 끝의 `요`(예: "맞아요")는 상관없습니다. 그 밖의 말에는 저장하지 않고 다시 묻습니다.

## 1. 사진 보내기

입력창의 **📷 사진 찍기**(PC는 웹캠, 휴대폰은 카메라 앱) 또는 **🖼 앨범에서 선택**을 씁니다. JPG/PNG만 받습니다. 새 사진을 보내면 새 식사 기록이 시작되고, 저장 전이던 이전 사진의 기록은 멈춥니다.

## 2. 먹은 양 말하기

| 먹은 양 | 이렇게 말하기 |
|---|---|
| 100% | 다 먹었어, 전부 먹었어, 다 먹음 |
| 50% | 절반, 절반만, 반만, 1/2, 50%, 반 먹었어 |
| 25% | 4분의 1, 사분의 일, 1/4, 25% |
| 75% | 4분의 3, 사분의 삼, 3/4, 75% |
| 0% | 안 먹었어, 하나도 안 먹었어 |

- 끝에 붙일 수 있는 말은 `먹었어 / 먹었어요 / 먹음 / 먹었음`입니다. `절반`, `1/4`처럼 숫자·비율은 이 말 없이 단독으로 써도 됩니다.
- 음식이 여러 개일 때:
  - 모두 같은 양: `전부 절반만 먹었어`, `다 먹었어`
  - 음식마다 다르게: `밥은 절반, 불고기는 다 먹었어`(`,` 또는 `그리고`로 구분)
  - 한 음식만: `갈비구이는 4분의 1 먹었어`
  - 음식 이름 없이 `절반만 먹었어`라고만 하면 "어떤 음식의 양을 바꿀까요?"라고 묻고 음식 이름 칩을 보여 줍니다.
- 다시 고치기: `아니, 4분의 1`

## 3. 저장하기

말하지 않으면 절대 저장하지 않습니다.

| 이렇게 말하기 | 동작 |
|---|---|
| `올려줘`, `저장해줘`, `기록해줘` (`올려`, `저장해`, `기록해`) | 바로 저장. 양을 말한 적이 없으면 100%로 저장 |
| `절반만 먹었어 올려줘`, `4분의 1, 저장해줘` | 양 바꾸기와 저장을 한 번에 |
| `맞아 올려줘` | 100%(또는 이미 말한 양)로 저장 |
| `응`, `맞아`, `그래`, `좋아`, `네`, `어` | 봇이 **"~로 기록할까요?"**라고 물었을 때만 저장. 다른 질문 뒤에는 그 질문에 대한 답으로만 처리 |

## 4. 날짜·식사 종류 바꾸기 (저장 전에만)

- 식사 종류: `아침`, `점심`, `저녁`, `간식`
- 날짜: `오늘`, `어제` (다른 날짜 표현은 이해하지 못함)
- 예: `점심으로 바꿔줘`, `어제 저녁으로`, `어제 저녁으로 올려줘`(바꾸고 바로 저장), `절반만 먹었어 어제 저녁으로 올려줘`
- 기본값은 오늘 날짜와 현재 시각 기준 식사 종류입니다. 05~10시는 아침, 11~15시는 점심, 16~21시는 저녁, 그 외는 간식입니다.

## 5. 음식 바꾸기 (저장 전에만)

- `갈비구이가 아니라 불고기야` — 앞은 화면에 나온 음식, 뒤는 150종 목록의 이름과 **정확히 같아야** 합니다. 띄어쓰기와 `_`는 같게 봅니다(예: "곰탕 설렁탕" = `곰탕_설렁탕`).
- 사진 인식이 실패했을 때(봇이 이름을 물을 때): `불고기`, `불고기야`
- 음식이 하나이고 봇이 "음식이 맞나요?"라고 물었을 때: `맞아`, 또는 다른 음식 이름

## 6. 멈추기

`아니야`, `아니`, `아냐`, `취소`, `그만`, `안할래`
→ 저장하지 않고 멈춥니다. 사진과 지금까지의 내용은 남아 있어서, 양을 다시 말하면 이어서 진행합니다.

## 7. 저장한 뒤 먹은 양 고치기

- `아니, 4분의 1` → 바뀔 내용을 보여 주고 "이렇게 바꿀까요?"라고 묻습니다. `응` → 저장
- `절반만 먹었어 저장해줘` → 바로 바꿈
- 저장한 뒤에는 **날짜·식사 종류·음식은 바꿀 수 없습니다**(지시서 R18, 팀 협의 과제). 요청하면 안내만 합니다.
- 히스토리 표의 **챗으로 수정** 버튼으로도 같은 말로 고칠 수 있습니다.

## 8. 답장 칩

봇 말풍선 아래 버튼입니다. 누르면 버튼에 정해진 문장이 내 메시지로 전송됩니다(직접 입력한 것과 같음).

| 칩 | 보내는 문장 |
|---|---|
| 다 먹었어 / 절반 | `다 먹었어 올려줘` / `절반만 먹었어` |
| 4분의 1 / 안 먹었어 | `4분의 1 먹었어` / `안 먹었어` |
| 응 / 아니야 / 맞아 | `응` / `아니야` / `맞아` |
| 아침·점심·저녁·간식 | `점심으로 바꿔줘` 등 |
| 음식 이름(대상 선택) | `갈비구이는` 등 → 다음에 양을 말하기 |
| 다른 사진도 기록하기 / 오늘의 식사 보기 | 사진 찍기 열기 / 홈으로 이동(메시지 전송 안 함) |

## 9. 알아듣지 못하는 말 (지시서 8.4 "확인 질문 예")

`조금`, `반쯤`, `더 먹었어`, `반 남겼어`, `반찬만 먹었어`, `반도 못 먹었어`, `다 못 먹었어`, `150%`, `절반보다 적게 먹었어`, `50%~75%`, `응 절반` 등
→ 저장하지 않고 `"절반", "4분의 1"처럼 말씀해 주시겠어요?`라고 다시 묻습니다.

`2인분 먹었어`, `두 그릇` → "지금은 한 번에 1인분 기준으로만 기록할 수 있어요"(지시서 R17: 채팅 기록은 1인분 기준 고정).

## 지시서 범위 밖 (지원하지 않음)

메뉴 추천("저녁 뭐 먹지?"), 오늘 섭취량 질문, 자유 대화, 운동 제안. LLM이 필요하거나 지시서에 정해지지 않은 기능이라 팀 결정이 먼저 필요합니다.
