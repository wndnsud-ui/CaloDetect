# 작업 전 필수 적용 규칙

코드·화면·데이터 변경 전에 아래 순서로 읽는다. 사용자 명시 지시가 우선하며, 구현 사실을 이유로 미확정 운영 정책을 승인된 것으로 취급하지 않는다.

1. [개발 규칙](DEVELOPMENT_RULES.md): 모든 변경에 적용.
2. [Master Spec 원문](CaloDetect_Codex_통합_업무지시서_20261002_v11.md): 원문 보존. 후속 승인된 범위·폐기는 아래 현재 기준으로 대조.
3. [현재 구현 기준](CURRENT_IMPLEMENTATION.md): 기능 범위·변경된 규칙·설정·코드 근거.
4. [결정 대기 사항](PENDING_DECISIONS.md): 운영 TBD를 임의 확정하지 않는다.
5. [변경 이력](../../CHANGELOG.md): 후속 승인·폐기·검증 확인.
6. [실행 및 팀 작업 절차](../../README.md): 실행법·작업 브랜치·PR·통합 절차.

## 규칙 문서 분류

| 문서 | 현재 용도 |
|---|---|
| DEVELOPMENT_RULES / CURRENT_IMPLEMENTATION | 현재 개발 규칙·구현 기준 |
| PENDING_DECISIONS | 아직 확정되지 않은 정책·미구현 범위 |
| Master Spec v11 | 최초 기준 원문. 수정 금지. 후속 승인사항으로 대체된 조항은 재적용하지 않음 |
| 커뮤니티 업무지시서 v5 | 커뮤니티 설계 참고. 리워드·랭킹 후속 변경은 현재 기준 우선 |
| 챗봇 통합구현지시서 v9 | 챗 기록 설계 참고. 모델 개선 수집 지시는 폐기, 플래그 동작 유지 |
| CaloPoint 기획안 v4 / 리워드 업무지시서 v3 | 설계·수치 출처. 닉네임 주기·캐릭터·관리자 위치·Stage 진행 상태는 현재 기준 우선 |
| SERVICE_CONSENT_DRAFT | 운영 미승인 검토용 초안. 환경변수에 자동 적용 금지 |
| 리워드 더미 테스트 실행 가이드 | 개발 전용 실행 절차. 테스트 계정만 허용, 초기화 시 교환 이력 삭제 주의 |

폐기된 모델 개선 업무지시서는 사용하지 않는다. Streamlit은 그래프 서버만 유지하며, 웹 관리자의 교환·닉네임 관리와 폐기된 재학습 QA를 혼동하지 않는다.
