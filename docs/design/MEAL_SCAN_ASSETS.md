# 식단 기록 화면 이미지

2026-10-27 사용자 제공 시안을 참고해 밝은 잎사귀 배너와 사진 분석·음식 확인 카드로 구성했다. 사용자가 이미지 생성과 기존 지방이 사용을 명시했다.

| 파일 | 용도 |
|---|---|
| frontend/public/images/meal-scan/leaf-banner.png | 햇살·녹색 잎사귀를 담은 넓은 배경, 왼쪽 제목 공간 확보 |
| frontend/public/images/meal-scan/food-cutout.png | 순두부찌개·밥·작은 반찬의 투명 배경 장식 사진 |
| frontend/public/images/meal-scan/korean-meal-collage.png | 후속 시안 반영: 한식 사진 프레임 2장·린넨·주변 잎사귀의 투명 콜라주. 현재 카드 장식에 사용 |

생성: 내장 image_gen 도구. 배너는 3:1의 밝은 웰니스 사진 배경, 왼쪽 여백·오른쪽 잎사귀·문구/로고 없음으로 요청. 음식은 한식 한 상을 사선 위에서 촬영한 사실적 투명 배경 이미지, 음식 전체 프레임 안에 배치·문구/캐릭터 없음으로 요청했다. 음식의 수치·추천·실제 분석 결과를 뜻하지 않는 장식이다.

후속 콜라주: 사용자가 첨부한 디테일 이미지의 큰 흰 둥근 프레임·오른쪽 아래 작은 사진·린넨·주변 초록 잎사귀 구성을 참고했다. 후속 요청에 따라 음식은 샐러드 대신 큰 사진에 순두부찌개·밥·김치·나물, 작은 사진에 불고기 한식 식사를 배치한다. 손글씨는 기존 HTML, 밑줄·노란 강조선은 SVG로 그려 글자와 선의 선명도를 유지한다.

오른쪽 캐릭터는 기존 `JibangFigure`에 현재 회원의 `level`과 `equipment`를 전달한다. 대체 캐릭터나 지방이 이미지는 생성하지 않았다.

제목·설명·버튼·손글씨 안내는 이미지에 합성하지 않고 HTML로 표시한다. 이미지 자체가 클릭이나 입력을 가로막지 않도록 장식은 pointer-events:none 처리한다. 사진 미리보기·웹캠 사용 중에는 음식 장식을 숨기고, 음식 행이 있으면 지방이 안내를 숨긴다. 모바일은 카드를 세로 배치한다.

컴포넌트: `frontend/src/MealScanDesign.jsx`. 스타일: `frontend/src/meal-scan.css`. 기존 API·영양 계산·아이템 ID·모델·CSV는 변경하지 않는다. 개별 PNG는 Vite 빌드 시 dist/images/meal-scan으로 복사된다.

검증: production build 통과, 이미지 2개와 빌드 출력의 SHA256 일치. 실제 컴포넌트를 사용한 테스트 화면에서 Chrome CDP 1440px·390px 이미지 로딩·가로 넘침 없음 확인. 음식 직접 추가 시 입력란 표시·지방이 안내 숨김, 샘플 PNG 선택 시 사진 미리보기·장식 숨김·분석 버튼 활성화 확인. 실제 모델 분석·저장 API는 이번 UI 검증에 포함하지 않았다.
