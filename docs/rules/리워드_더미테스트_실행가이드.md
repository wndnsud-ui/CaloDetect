# 리워드 더미 테스트 실행 가이드

> 대상: CaloDetect 팀원 (각자 PC의 Docker DB 사용)
> 기준일: 2026-10-20 · 브랜치: `feature/rewards` (병합 후에는 `develop`)
> 목적: 테스트 계정에 포인트·XP·연속 기록 더미를 만들어 리워드 화면(홈 카드·지방이 방·성장·랭킹·리워드 몰)을 바로 확인하기

이 가이드는 **로컬 개발 환경 전용**입니다. 더미는 테스트 계정에만 들어가고, 운영 설정에서는 테스트 메뉴와 경로가 생기지 않습니다.

| 항목 | 값 |
|---|---|
| 웹 주소 | http://localhost:5174 |
| 테스트 계정 | `test@calodetect.local` / `CaloTest!2026` |
| 관리자 계정 | `admin@calodetect.local` / `CaloAdmin!2026` (쿠폰 발급·교환 처리·닉네임 관리) |
| 필요한 서버 | Backend 8000 · 그래프 8502 · 웹 5174 |

아래 명령은 모두 **PowerShell**, 프로젝트 폴더가 `C:\projects\CaloDetect`인 기준입니다. 다른 위치에 받았다면 경로만 바꾸세요.

## 0. 확인할 설정 (`.env`)

프로젝트 폴더의 `.env`에 아래 값이 있어야 합니다. `scripts\setup_local.ps1`로 설정했다면 대부분 이미 들어 있습니다.

```text
APP_ENV=development
LOCAL_TEST_SIGNUP=true
FRONTEND_ORIGIN=http://localhost:5174
# 선택: 이 시각 이후 가입자는 가입 보너스와 "닉네임 정하기" 단계를 받습니다.
REWARD_ONBOARDING_START_AT=2026-10-20T00:00:00+09:00
```

`.env`는 GitHub에 올리지 않습니다.

## 1. 최신 코드 받기 · DB 준비

처음 한 번, 그리고 코드를 새로 받을 때마다 실행합니다. Docker Desktop을 먼저 켜 두세요.

```powershell
Set-Location 'C:\projects\CaloDetect'
git fetch
git switch feature/rewards
git pull

docker compose up -d db
.\.venv-backend\Scripts\python.exe -m pip install -r backend/requirements-dev.txt
.\.venv-backend\Scripts\python.exe -m alembic -c backend/alembic.ini upgrade head
.\.venv-backend\Scripts\python.exe -m backend.scripts.seed_reward_items
```

`upgrade head` 뒤에 오류가 없으면 리워드 테이블이 준비된 것입니다.

## 2. 서버 3개 켜기 (터미널 3개)

VS Code에서 **터미널 → 새 터미널**로 창 3개를 열고 각각 실행합니다. 켠 창은 닫지 마세요.

**터미널 A — Backend (8000)**

```powershell
Set-Location 'C:\projects\CaloDetect'
$env:FRONTEND_ORIGIN='http://localhost:5174'
.\.venv-backend\Scripts\python.exe -m uvicorn backend.app.main:app --reload --host ::1 --port 8000
```

**터미널 B — 그래프 서버 (8502)**

```powershell
Set-Location 'C:\projects\CaloDetect'
.\.venv-backend\Scripts\python.exe -m streamlit run streamlit/charts.py --server.address 127.0.0.1 --server.port 8502 --server.headless true --browser.gatherUsageStats false
```

**터미널 C — 웹 (5174)**

```powershell
Set-Location 'C:\projects\CaloDetect\frontend'
npm.cmd ci
$env:CALODETECT_API_TARGET='http://[::1]:8000'
npm.cmd run dev -- --host localhost --port 5174
```

> Backend도 Docker로 실행하는 팀원은 터미널 A 대신 `docker compose up -d --build backend`를 실행합니다. 코드를 새로 받을 때마다 `--build`가 필요합니다.

## 3-A. 버튼으로 더미 만들기 (추천)

1. http://localhost:5174 에 접속해 테스트 계정으로 로그인합니다.
   - 테스트 계정이 없다는 오류가 나면 먼저 `.\.venv-backend\Scripts\python.exe -m backend.scripts.seed_local_test_account`를 실행합니다.
2. 왼쪽 메뉴 맨 아래 **테스트**를 누릅니다.
3. 빠른 설정을 고르거나 값을 직접 입력합니다.

   | 빠른 설정 | 포인트 | XP | 연속 기록 | 보호권 |
   |---|---:|---:|---:|---:|
   | 처음 시작(LV.1) | 30 | 0 | 0일 | 0장 |
   | LV.2 직전 | 60 | 290 | 4일 | 0장 |
   | LV.3 | 200 | 1,200 | 5일 | 1장 |
   | LV.5 만렙 | 800 | 5,200 | 13일 | 2장 |

4. **더미 실행**을 누릅니다. "기존 리워드 기록을 지우고 새로 넣기"가 체크돼 있으면 이전 더미를 지우고 새로 넣습니다.
5. 결과 카드의 버튼(홈 카드 보기 · 지방이 방 · 성장 · 랭킹 · 리워드 몰)으로 화면을 확인합니다. 레벨이 올랐다면 다음 화면에서 축하 창이 뜹니다.
6. 처음 상태로 돌리려면 **리워드 초기화**를 누릅니다. 교환 신청·발급 쿠폰을 포함한 리워드 기록을 지우고 식단·닉네임은 그대로 둡니다.

## 3-B. 명령으로 더미 만들기

**한 번에 전부** (테스트 계정 → 최근 30일 식단 → 리워드 아이템 → 리워드 더미)

```powershell
# Backend를 PC에서 실행하는 경우
Set-Location 'C:\projects\CaloDetect'
.\.venv-backend\Scripts\python.exe -m backend.scripts.seed_test_demo

# Backend를 Docker로 실행하는 경우
docker compose exec backend python -m backend.scripts.seed_test_demo
```

여러 번 실행해도 같은 날 같은 값은 중복으로 쌓이지 않습니다.

**리워드 값만 바꿔서**

```powershell
.\.venv-backend\Scripts\python.exe -m backend.scripts.seed_reward_demo --points 800 --xp 5200 --streak 13 --protectors 2 --reset
```

| 옵션 | 기본값 | 의미 |
|---|---|---|
| `--points` | 200 | 리워드 몰에서 쓸 포인트 |
| `--xp` | 1200 | XP 총량 (300 → LV.2 · 1,000 → LV.3 · 2,500 → LV.4 · 5,000 → LV.5) |
| `--streak` | 5 | 어제까지 이어진 연속 기록 일수 (오늘은 직접 기록해서 확인) |
| `--protectors` | 1 | 연속 기록 보호권 수 |
| `--reset` | 없음 | 테스트 계정의 리워드 기록을 지우고 다시 넣기 |

명령을 실행한 뒤에는 브라우저를 새로고침하면 반영됩니다.

## 3-B-1. 리워드몰 v1.3 시연 시나리오

교환 기능이 켜진 상태(`REWARD_EXCHANGE_ENABLED=true`, `REWARD_EXCHANGE_GLOBAL_MONTHLY_CAP=100`)에서 테스트 계정으로 로그인한 뒤 실행합니다. 기존 리워드 기록을 지우고 다시 만듭니다(식단·닉네임은 유지).

| 시나리오 | 만드는 상태 |
|---|---|
| `v13` | 실물 교환에 쓸 수 있는 포인트 320P, 이번 달 꾸미기 구매 2건(물병 40P·하트 쿠션 60P), 지난달 교환 2건(사용 완료 프로틴바·사용 가능 에너지 드링크), 이번 달 교환 0건, 목표 진한홍삼 프리미엄 30포 |
| `v13_coaching` | `v13` + 포인트 760P(코칭 이용권 구매 시연) |

왼쪽 아래 **테스트** 메뉴에서 **v13 시연** 또는 **v13 코칭 시연** 버튼을 누릅니다(`POST /dev/demo/rewards` body `{"scenario": "v13"}`).

콜라보 기획전·진한홍삼 목표를 보려면 `REWARD_COLLAB_DEMO_ENABLED=true`, 코칭을 보려면 `REWARD_COACHING_ENABLED=true`를 `.env`에 넣고 Backend를 다시 켭니다. 가입 14일 조건은 `REWARD_EXCHANGE_MIN_ACCOUNT_DAYS=0`으로 시연합니다.

## 3-C. 건강상품 교환 · 쿠폰 발급 확인

1. `.env`에 아래를 넣고 Backend를 다시 시작합니다. (`REWARD_EXCHANGE_MIN_ACCOUNT_DAYS=0`은 가입 14일 조건을 끄는 로컬 테스트용입니다.)
   ```text
   REWARD_EXCHANGE_ENABLED=true
   REWARD_EXCHANGE_GLOBAL_MONTHLY_CAP=100
   REWARD_EXCHANGE_MIN_ACCOUNT_DAYS=0
   ```
2. 관리자 계정이 없으면 `.\.venv-backend\Scripts\python.exe -m backend.scripts.seed_local_admin`을 실행합니다.
3. 테스트 계정으로 교환 신청 → 관리자 계정으로 로그인 → 왼쪽 **관리자** → **교환 신청 처리**에서 **쿠폰 발급**(쿠폰 번호·유효기간 입력) → 다시 테스트 계정으로 쿠폰함 확인 순서로 봅니다.
4. 교환은 한 달에 한 번이라, 다시 시험하려면 테스트 페이지의 **리워드 초기화**를 누르세요(교환 기록도 지워짐).

## 4. 확인하면 좋은 것

| 화면 | 확인 |
|---|---|
| 홈 | 리워드 카드(잔액·레벨·목표·오늘 더 받을 수 있는 것), 기록 안내 카드의 지방이 |
| 음식 추가 → 저장 | 오른쪽 보상 패널(+P·+XP), 끼니별 현황 |
| 리워드 → 리워드 몰 | 아이템 구매 → 가입 보너스 등 꾸미기 전용 포인트가 먼저 차감되는지 |
| 리워드 → 지방이 방 | 배경 고르기·적용, 잠긴 레벨 배경 미리보기, 꾸미기 착용·벗기 |
| 리워드 → 성장 · 랭킹 | 레벨 로드맵, 이번 주 연속 기록·보너스 칸, 요일별 XP 그래프, 미션, 랭킹 닉네임 바꾸기 |
| 마이페이지 | 이름 아래 닉네임 행, 닉네임 바꾸기 |

화면이 어색하거나 오류가 나면 화면 캡처와 함께 단톡방에 공유해 주세요.

## 5. 문제가 생기면

| 증상 | 해결 |
|---|---|
| 왼쪽에 **테스트** 메뉴가 없음 | `.env`의 `APP_ENV=development`, `LOCAL_TEST_SIGNUP=true` 확인 후 Backend 재시작 (Docker는 `docker compose up -d --build backend`) |
| "테스트 계정으로 로그인하면…" 안내만 보임 | 다른 계정으로 로그인한 상태입니다. 로그아웃 후 테스트 계정으로 로그인 |
| `Local development test settings required` | `.env`가 개발용 설정이 아닙니다 (0단계 확인) |
| `Local test account missing` | `.\.venv-backend\Scripts\python.exe -m backend.scripts.seed_local_test_account` 실행 |
| `relation "reward_..." does not exist` 또는 화면에 DB 오류 | 1단계 `alembic upgrade head`를 실행하지 않았습니다 |
| 성장 탭 그래프가 비어 있음 | 터미널 B 그래프 서버 확인: http://localhost:8502/_stcore/health 에 `ok` |
| `Port 5174 is already in use` | 이전 웹 서버 창을 `Ctrl+C`로 종료한 뒤 다시 실행 |
| 리워드 메뉴의 포인트가 바로 안 바뀜 | 브라우저 새로고침 |
