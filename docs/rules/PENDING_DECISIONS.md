# 보류 및 결정 대기 사항

마지막 정리: 2026-10-02

미확정 UX·정책·운영 사항을 이 문서에서 관리합니다. 참고 이미지와 제안 수치는 승인된 기본값으로 사용하지 않습니다. 결정되면 상태와 결정 내용을 갱신하고 `CHANGELOG.md`에 결정일·근거·영향 범위를 기록합니다. Master Spec 원문은 보존합니다.

## 목표 설정 UX — 적용, 정책 결정 대기

2026-10-03 사용자 후속 요청으로 참고 이미지 기반 화면 UX를 적용합니다. 목표 유형 카드·성별 버튼·기본 정보·칼로리 조절과 계산 확인 후 저장 흐름을 구현합니다. 탄단지 비율 확정은 계속 보류합니다. 칼로리 조절은 UI에서 50 kcal 단위이며 허용값 검증과 영양 계산은 기존 Backend가 수행합니다.

| 항목 | 결정할 내용 | 현재 처리 |
|---|---|---|
| 목표 설정 화면 | 목표 유형 카드, 성별 버튼, 기본 정보 배치 | 적용 |
| 단계 흐름 | 왼쪽 정보 입력 → 오른쪽 계산 결과 확인·저장 | 적용; 저장 후 두 카드 유지, 모바일은 세로 배치; 비회원은 계산 확인까지 |
| 나이 입력 | 정확한 만 나이 입력 유지 또는 연령대 선택 추가 | 기존 만 나이 입력 유지 |
| 활동 수준 | 입력 방식과 단계별 배치 | 기존 계산에 필요한 입력 유지 |
| 목표 칼로리 조절 | 정책 기본값과 계산 결과 자동 반영 여부 | 기존 저장값 우선; 신규 입력 2,000 kcal 유지; UI 증감 50 kcal; Backend 검증 유지 |
| 탄단지 목표 | 기본 비율, 사용자 조절 여부, 합계 검증, 저장·추천 반영 범위 | 미적용; 이미지의 탄수화물 50%·단백질 25%·지방 25% 미확정 |

## 서비스 정책·운영 — 결정 대기

| 항목 | 결정할 내용 | 현재 처리 |
|---|---|---|
| 필수 동의 문구 | 서비스 이용·개인정보 동의 최종 문구와 적용 시점 | [검토용 초안](SERVICE_CONSENT_DRAFT.md)만 작성; 운영 자동 적용 안 함 |
| 모델 개선 선택 동의 | 최종 문구와 활용 범위 | 승인된 문구 설정 후 활성화; 관리자 QA 조건 유지 |
| 이미지 보관 | 운영 저장 위치, 보관기간, 삭제 방법·시점 | 로컬 테스트 설정 유지; 1년 보관은 미확정 |
| 승인 후보의 동의 철회 | 이미 QA 승인된 후보의 철회·삭제·후속 처리 | 대기 샘플 제외와 승인 이력 보존 동작 유지; 후속 정책 미확정 |
| 추천 운영 기준 | 출처 최종 승인, 가중치, 최근 식사 범위 N, 필터와 끼니 적합성 | 기존 CSV 기반 개발 설정 유지; 운영 기준 미확정 |
| 당류·나트륨 목표 | 기준, 단위, 대상 및 추천·화면 반영 방식 | 목표 평가 미적용 |
| Google 서비스 등록 | 제공자 등록 정보, 운영 도메인·반환 URL, 실제 인증 검증 일정 | 사용자 요청(2026-10-07)으로 Google GIS/Authorization Code + PKCE 로컬 흐름 구현; 공개 Client ID는 `.env.example`, state key와 선택 Client Secret은 비공개 로컬 설정에 저장. Google 테스트 계정 실인증 대기. Google 실인증·운영 도메인·운영 승인은 대기; Apple은 사용자 결정(2026-10-07)으로 진행하지 않음 |
| 운영 배포 | 배포 대상과 운영 환경 설정 | 미확정 |

## 이미 확정된 사항

다음 항목은 결정 대기에 포함하지 않습니다.

- 가입·로그인 최소 연령: 만 18세.
- 인증: 이메일/비밀번호와 HttpOnly 세션 쿠키. 사용자 결정(2026-10-07)으로 소셜 로그인은 Google만 진행하며 Apple 버튼과 인증 초기화는 화면에서 제거.
- 영양 데이터: 기존 `CaloDetect_nutrition_all_matched.csv` 사용 승인. 기존 `class_id`·`food_name` 연결 보존.

기존 [구현 계획](../planning/IMPLEMENTATION_PLAN.md)의 초기 TBD 표보다 이후 [변경 이력](../../CHANGELOG.md)의 명시적 승인 내용을 우선하여 정리했습니다.
